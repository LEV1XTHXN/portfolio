game engine

glacier

A real-time 3D engine written from scratch in C++ on top of Vulkan, built for my university project together with the game running on it.

what is inside

  • Vulkan renderer

    Swapchain, render passes, pipelines and descriptor management written directly against the Vulkan API.

  • Entity-component system

    Data-oriented storage that keeps components contiguous in memory so systems iterate them in cache order.

  • Asset pipeline

    Loads meshes, textures and materials, then uploads them to GPU memory through staging buffers.

  • Scene & camera

    Transform hierarchy with a perspective camera, view frustum culling and per-frame uniform updates.

  • Platform layer

    Window creation, surface setup and buffered keyboard and mouse input behind one interface.

  • Game loop

    Fixed-step update decoupled from rendering, with frame timing and resource lifetime handled by the engine.

main.cpp

// Everything the engine needs to put a scene on screen.
int main() {
    glacier::Engine engine{ "Glacier", 1280, 720 };

    auto& scene = engine.createScene();
    auto  model = engine.loadModel("assets/level.obj");

    auto entity = scene.createEntity();
    entity.add<Transform>({ .position = { 0.0f, 0.0f, 0.0f } });
    entity.add<MeshRenderer>({ .model = model });

    scene.addSystem<PlayerController>();

    // Fixed-step update, rendering runs as fast as the GPU allows.
    while (engine.isRunning()) {
        engine.update();
        engine.render(scene);
    }
}
